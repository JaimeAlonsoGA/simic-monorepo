Every meeting, written down. On your machine.

Simic records any call on Linux, transcribes it locally with Whisper and leaves a Markdown note in your Obsidian vault. No bot in the meeting, no account, no upload.

A meeting recorder that stays out of the way

Free and open source, built for hour-long calls on a Linux desktop.

Private by default

faster-whisper transcribes on your CPU or GPU. Nothing leaves the machine unless you opt into a remote provider.

Any call app

It records what your computer plays and what your mic hears through PipeWire or PulseAudio, so it works with any app.

Obsidian-native notes

Markdown with YAML frontmatter, timestamps and speakers, dropped straight into your vault.

You and them, apart

Your mic and the other side are recorded on separate channels, so what is labelled “You” is really you.

Nothing lost

A crash, a Ctrl+C or a failed run keeps the recording until there is a note. simic recover finishes it.

Summaries, if you want them

Optional LLM summaries and action items: Anthropic, OpenAI, Groq, Gemini, DeepSeek, OpenRouter or Qwen. Emails, phone numbers and names you list can be masked before it is sent.

Who said what

Optional speaker diarization with pyannote names each voice in group calls.

Terminal, window or tray

simic start in a terminal, a GTK window, or a tray icon that shows when it is recording.

How it works

Three steps, and the last one happens without you.

  1. Press record when the call starts.

    Click the button in the window or tray, or run simic start.

  2. Stop when it ends.

    Your terminal comes back at once. Light MP3 capture, about 60 MB an hour.

  3. Read the note.

    Simic transcribes it in the background, and a desktop notification tells you when it is in your vault.

Install

Linux with PipeWire or PulseAudio, Python 3.13 or newer, and ffmpeg.

# 1. System dependencies (Debian / Ubuntu shown)
sudo apt install ffmpeg pulseaudio-utils

# 2. Simic, with uv
uv tool install --python 3.13 git+https://github.com/JaimeAlonsoGA/simic-monorepo

# 3. Check and record
simic doctor        # is everything a meeting needs in place?
simic start         # Ctrl+C to stop

Notes go to ~/simic/meetings/. To use your Obsidian vault instead, set SIMIC_VAULT_PATH in ~/.config/simic/.env. Nix users can run nix run github:JaimeAlonsoGA/simic-monorepo. Extras such as the tray, summaries and diarization are covered in the README.

Questions

Does Simic send my meetings to the cloud?
No. Whisper transcribes on your own machine. Audio leaves it only if you opt into remote transcription (OpenAI), and text only if you turn on an LLM summary; emails, phone numbers and names you list can be masked first.
Which call apps does Simic work with?
Any of them. Simic records at the system level, so Google Meet, Zoom, Microsoft Teams, Telegram, Discord, Slack huddles and browser calls all work. No bot joins the call.
Do I need Obsidian?
No. Simic writes plain Markdown files to ~/simic/meetings by default. Point SIMIC_VAULT_PATH at an Obsidian vault and the notes appear there.
Does it need a GPU?
No. faster-whisper runs on the CPU by default. An NVIDIA GPU with CUDA makes transcription and speaker diarization much faster.
What happens if my computer crashes during a meeting?
The recording is kept until a note exists. simic status lists what is pending and simic recover finishes it.
Is Simic free?
Yes. Simic is open source under the Apache 2.0 license.
